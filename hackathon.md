## Project

- **Name:** ImpactGraph, selected by the builder on 2026-10-10.
- **Idea, purpose, and problem:** Architecture-aware change-impact investigation and verification for local React/Next.js projects. The trusted-sample application now has a local web interface.
- **Architecture:** A deterministic TypeScript Compiler API dependency graph, Git diff analyzer, bounded OpenRouter agent, reviewed verification checks with per-command human approval, and a Next.js App Router interface with React Flow.
- **Stack and integrations:** TypeScript, Next.js, Tailwind CSS, React Flow, official OpenRouter TypeScript SDK with configurable `deepseek/deepseek-v3.2`, and neatlogs instrumentation. Entire remains configured for development checkpoints; cfo.ai business plan pending.
- **Team:** Undecided; publish names or handles only with each person's consent.
- **Demo URL and reproduction steps:** Local only: run `npm run dev` and open `http://127.0.0.1:3000`; see README for the approval workflow. No public deployment exists.
- **Known limitations and next steps:** Hosted neatlogs processing is not verified for recent agent traces. The verification runner is for trusted local samples, and the web app has no durable run database. Resolve telemetry with support, prepare remaining competition evidence, and recheck submission requirements with the builder.
